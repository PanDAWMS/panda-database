# PanDA Database Schema Patch 0.0.25

**Version:** 0.0.25
**Upgrade from:** 0.0.24

## Overview

This patch adds worker-node tracking:

- `doma_panda.worker_node` (new table)
- `doma_panda.update_worker_node_map` procedure and daily job
- `doma_panda.update_worker_node_metrics` procedure and daily job

## Files in this Patch

1. **0.0.25.patch.sql** — Main DB updates (run against `panda_db`)
2. **0.0.25.cron.patch.sql** — Cron job updates (run where `pg_cron` is installed)
3. **0.0.25.README.md** — This file

## Order of Operations

1. Apply `0.0.25.patch.sql` to `panda_db`
2. Apply `0.0.25.cron.patch.sql` to the DB that hosts `pg_cron`
