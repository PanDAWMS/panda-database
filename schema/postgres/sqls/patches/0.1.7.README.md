# PanDA Database Schema Patch 0.1.7

**Version:** 0.1.7
**Upgrade from:** 0.1.6

## Overview

This patch adds a per-PANDA_QUEUE breakdown of worker node metrics (ATLASPANDA-1833):

- `doma_panda.worker_node_metrics_by_queue` (new table)
- `doma_panda.update_worker_node_metrics_queue` procedure and daily job

## Files in this Patch

1. **0.1.7.patch.sql** — Main DB updates (run against `panda_db`)
2. **0.1.7.cron.patch.sql** — Cron job updates (run where `pg_cron` is installed)
3. **0.1.7.README.md** — This file

## Order of Operations

1. Apply `0.1.7.patch.sql` to `panda_db`
2. Apply `0.1.7.cron.patch.sql` to the DB that hosts `pg_cron`
